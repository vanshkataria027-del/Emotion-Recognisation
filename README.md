# Emotion Recognition using CNN

## About
Real-time emotion detection using CNN trained on FER2013 dataset.

## Emotions Detected
Angry, Disgust, Fear, Happy, Neutral, Sad, Surprise

## Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- FER2013 Dataset

## How to Run
1. Install: pip install tensorflow opencv-python matplotlib numpy
2. Train: python train.py
3. Predict: python predict.py
